# crabcheck

Property-based testing for Rust, designed for tests written by coding agents:
one generator gives you generation, shrinking, mutation-based targeting, and
seed replay; every run produces a machine-readable report; everything is
configurable through environment variables or a JSON file.

**Status:** 0.2 is a rewrite in progress. The published 0.1.0 API is not
supported by this branch. Follow the repository for progress.
